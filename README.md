## ChatGPT Plus / Pro 怎么选？

日常写作、学习、整理资料和编程辅助，可以先评估 Plus；高频使用、有更高额度需求，再核对 Pro 的具体档位。官方计划的可用性与权益以 [ChatGPT 账户内展示](https://chatgpt.com/)为准。

购买商城商品时，重点看清三件事：**交付到哪个账号、包含什么权益、有效期多久**。商品写的是成品号、卡密或自有账号服务，流程就可能不同，不能只比较标题里的价格。

## 下单后怎么查？

1. 保存订单号和订单链接。
2. 打开[订单查询](https://shop.wagbrio.com/user/index/query)，核对付款与交付状态。
3. 需要售后时，登录商城，在个人中心提交工单。

“已付款”表示支付已确认，“已发货／已交付”才表示交付内容已经提供。付款后没有自动跳回商城，先查订单，避免重复付款。

**现在多少钱？** 查看[商城商品详情](https://shop.wagbrio.com/)，这里不把历史价格写成实时报价。
